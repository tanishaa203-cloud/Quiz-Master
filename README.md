# Quiz Master

A desktop quiz app made with Python for CSE 466 (Python-Based Project Development).

## Features
- 4 categories: Science, Geography, General Knowledge, Computer & Python
- 5 random medium-to-hard questions in every game
- 15-second timer for each question
- Score and result screen with a Play Again button
- Scores saved in an SQLite database
- Leaderboard showing the top 5 players in each category

## Tools used
- Python: main programming language
- Tkinter: windows, buttons and screens
- SQLite: saving scores and the leaderboard

## How to run
1. Install Python 3
2. Download quiz.py
3. Open Command Prompt in the same folder and run: python quiz.py
